# 🎓 График на учебните занятия · МБИС (ТУ-София)

Интерактивна програма по седмици и дни за специалност **„Мениджмънт и бизнес информационни системи“ (ММБИС)**, Стопански факултет, Технически университет – София (зимен семестър 2026/2027).

---

## 📱 Функции
- 🎯 **Интерактивност:** Филтриране по група (201А, 201Б, 202А, 202Б, 203) и изглед (всички седмици / само със занятия).
- 📍 **Бутон „Днес / Сега“:** Автоматично позициониране и пулсиращо осветяване на текущия ден и занятие.
- 📱 **Mobile First:** Оптимизиран интерфейс за телефон с възможност за запазване като икона на началния екран.
- 🤖 **Автоматично следене:** GitHub Actions робот проверява всяка сутрин официалния PDF на ТУ-София и изпраща имейл известие при промени.

---

## ⚙️ Автоматизация (GitHub Actions)
Автоматичният процес се изпълнява всяка сутрин в 08:00 ч. българско време:
1. Изтегля актуалния PDF от официалния адрес на ТУ-София.
2. Сравнява SHA-256 хеша с `schedule_hash.txt`.
3. При засечена промяна изпраща имейл известие с прикачените файлове и обновява страницата.
